Análisis de Sistemas y Señales

Modelado matemático y simulación de un circuito de primer orden

Diagrama del Circuito

1. Ecuación Diferencial (Dominio del Tiempo)

Aplicando la Ley de Voltajes de Kirchhoff (LVK) a la malla del circuito, la suma de las caídas de voltaje es igual al voltaje de entrada:

$$v_{in}(t) = v_{R1}(t) + v_{R2}(t) + v_C(t)$$

Expresando en función de la corriente $i(t)$ y sabiendo que el voltaje de salida se toma en la rama de $R_2$ y $C$:

$$v_{out}(t) = R_2 i(t) + \frac{1}{C} \int i(t) dt \implies i(t) = \frac{v_{in}(t) - v_{out}(t)}{R_1}$$

Sustituyendo la corriente y derivando respecto al tiempo para eliminar la integral, obtenemos la ecuación diferencial que modela el sistema:

$$(R_1 + R_2) \frac{d v_{out}(t)}{dt} + \frac{1}{C} v_{out}(t) = R_2 \frac{d v_{in}(t)}{dt} + \frac{1}{C} v_{in}(t)$$

2. Función de Transferencia (Laplace)

Para obtener la función de transferencia $H(s) = V_{out}(s)/V_{in}(s)$, aplicamos la transformada de Laplace a la ecuación diferencial asumiendo condiciones iniciales nulas:

$$(R_1 + R_2)s V_{out}(s) + \frac{1}{C} V_{out}(s) = R_2 s V_{in}(s) + \frac{1}{C} V_{in}(s)$$

Factorizando y despejando la relación entre salida y entrada:

$$H(s) = \frac{R_2 s + \frac{1}{C}}{(R_1 + R_2)s + \frac{1}{C}} = \frac{R_2 C s + 1}{(R_1 + R_2)C s + 1}$$

3. Análisis Fasorial (Impedancias)

En estado estacionario senoidal, podemos analizar el circuito usando impedancias complejas donde $s = j\omega$. Las impedancias de los componentes son:

$$Z_{R1} = R_1, \quad Z_{R2} = R_2, \quad Z_C = \frac{1}{j\omega C}$$

Definimos la impedancia donde tomamos la salida ($Z_{out}$) y aplicamos el principio del divisor de voltaje:

$$Z_{out} = Z_{R2} + Z_C = R_2 + \frac{1}{j\omega C}$$ $$V_{out} = V_{in} \left( \frac{Z_{out}}{Z_{R1} + Z_{out}} \right) \implies H(j\omega) = \frac{Z_{out}}{Z_{R1} + Z_{out}}$$

Sustituyendo las impedancias y multiplicando el numerador y denominador por $j\omega C$ para simplificar:

$$H(j\omega) = \frac{R_2 + \frac{1}{j\omega C}}{R_1 + R_2 + \frac{1}{j\omega C}} = \frac{j\omega R_2 C + 1}{j\omega (R_1 + R_2) C + 1}$$

Comprobación: Como podemos observar, el resultado del divisor de tensión fasorial $H(j\omega)$ es exactamente el mismo que se obtiene al sustituir $s = j\omega$ en la función de transferencia de Laplace $H(s)$ encontrada en el paso anterior.
