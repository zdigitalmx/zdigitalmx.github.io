Simulador Biomecánico: Modelo de 3 Grados de Libertad (Pierna)

1. Justificación Matemática y Dinámica del Sistema

El sistema se modela como un manipulador robótico de tres eslabones interactuando con la gravedad en el plano sagital. La dinámica no lineal se obtiene mediante la formulación clásica de Euler-Lagrange:

M(θ)θ'' + C(θ, θ')θ' + G(θ) = τ

Donde θ = [θ1, θ2, θ3]T es el vector de ángulos articulares. La estabilización se logra mediante un control multivariable en lazo cerrado que emula el sistema neuromuscular:

Control de Impedancia Biológica:
τ = Kp(θref - θ) - Kdθ' + G(θ)

Cinemática Directa

Define la posición final del centro de masa del tronco (XT, YT) a partir de los ángulos articulares. Si la base (pie) está en (0,0):

XT = L1·sin(θ1) + L2·sin(θ2) + L3·sin(θ3)
YT = L1·cos(θ1) + L2·cos(θ2) + L3·cos(θ3)

Cinemática Inversa y Redundancia

Dado que tenemos 3 grados de libertad (n=3) para posicionar el centro de masa en un plano 2D (m=2), el sistema es redundante. Para hallar las velocidades articulares θ' necesarias para una trayectoria X' deseada, se emplea el Jacobiano J(θ) y la matriz pseudoinversa de Moore-Penrose J†:

X' = J(θ)·θ' => θ' = J†(θ)·X'

Donde: J† = JT(J·JT)-1

J(θ) =
L1cos(θ1)    L2cos(θ2)    L3cos(θ3)
-L1sin(θ1)   -L2sin(θ2)   -L3sin(θ3)
