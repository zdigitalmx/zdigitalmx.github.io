Simulador Biomecánico: Modelo de 3 Grados de Libertad

Justificación Matemática

El sistema se modela como un manipulador robótico de tres eslabones interactuando con la gravedad. La dinámica no lineal se obtiene mediante la formulación de Euler-Lagrange:

M(θ)θ'' + C(θ, θ')θ' + G(θ) = τ

Donde:

  • θ = [θ1, θ2, θ3]T es el vector de coordenadas generalizadas (ángulos absolutos respecto a la vertical).
  • M(θ) es la matriz de inercia (3x3), simétrica y definida positiva.
  • C(θ, θ') es la matriz de fuerzas centrípetas y de Coriolis (3x3).
  • G(θ) es el vector de pares gravitacionales, dependiente de la masa del tronco MT.
  • τ = [τ1, τ2, τ3]T es el vector de torques de entrada en las articulaciones (tobillo, rodilla, cadera).

Para el análisis en la licenciatura, el sistema se linealiza alrededor de un punto de equilibrio (postura vertical, θ ≈ 0), obteniendo la representación en espacio de estados:

Δx' = A·Δx + B·Δu
Δy = C·Δx + D·Δu

Para estabilizar la planta (que naturalmente tiene polos en el semiplano derecho), implementamos un control en lazo cerrado τ = Kp(θref - θ) - Kdθ' + G(θ), que emula la rigidez muscular, el amortiguamiento viscoso y la propiocepción del sistema biológico.
